PROTOTYPES

Bancs d'essai isolés. Une fonctionnalité y est mise au point avant d'entrer dans le jeu — voir docs/ARCHITECTURE_PROTOTYPES.md.

🧍 Créateur de personnage
Anatomie modulaire, genres, proportions, teintes. npm run proto:charactere
🗺️ Éditeur de monde
Palette, gizmo, terrain, splines, calques. npm run proto:editeur
⚔️ Combat
Scène vide + personnage animé. Enchaînements et fenêtres de combo. npm run proto:combat
